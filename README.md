# Ducksnsuits

A static website for the **Ducksnsuits** NFT collection — rare pixelated ducks dressed in fancy suits, shirts, and ties, each with unique genetics and apparel generated using Python algorithms.

## Overview

Ducksnsuits is a personal NFT project built with the aim of doing something greater. 20% of every sale is donated to a portfolio of clean and renewable energy companies, giving back to collectors who support the mission.

The collection features 100 unique ducks listed on OpenSea, with continuous improvements being made to both the generation code and the website.

## Running Locally

No build tools needed — it's a static site.

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.
